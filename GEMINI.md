# Project: AI Interview Agent

## Conventions
- Architecture: Clean architecture (separate UI, prompts, evaluation, database, models, utilities).
- Language: Python
- Libraries: Streamlit, Google Gemini API, SQLite
- Code Style: Production-quality, modular, typed.
- Documentation: Maintain clear README and internal documentation.

## Guidelines
- Follow the Research -> Strategy -> Execution lifecycle for all tasks.
- Wait for user confirmation between phases.
- Ensure all code is testable and maintainable.
- Do NOT generate everything at once.
