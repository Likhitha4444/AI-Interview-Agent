# AI Interview Agent

An AI-powered interview system for the Rooman Technologies 24-Hour AI Challenge.

## Features
- Generates 5 role-specific interview questions.
- Streamlit-based candidate interface.
- AI-driven individual answer evaluation (score out of 10 + feedback).
- Overall interview scoring and hiring recommendation.
- Transcript saving (JSON) and metadata persistence (SQLite).

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- SQLite
